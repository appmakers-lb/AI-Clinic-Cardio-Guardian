# Feature Baseline — V1 Research Foundation

## Market-derived baseline to pursue
- automated best-frame support
- vessel segmentation / labels / centerlines
- QCA: diameter, length, stenosis measurements
- multi-view / 3D reconstruction research
- whole-tree physiology mapping
- angiography-derived physiology research
- IVUS/OCT + physiology co-registration
- pre/post-PCI review
- physician correction tools
- PACS/DICOM workflow
- local/offline time-critical inference target

## AI Clinic Cardio Guardian differentiators
- Guardian Mode: watches every run, not only selected lesions
- Whole-case coronary memory
- Coverage Guardian: tracks what was not adequately visualized
- Multi-view lesion identity
- Evidence Bundle / Show Me Why
- voice + text grounded Q&A
- uncertainty / abstention engine
- multimodal disagreement engine
- remote second-cardiologist mode
- vendor-neutral adapter architecture
- complete audit/model version traceability

No feature is called clinically ready until its validation gate passes.
